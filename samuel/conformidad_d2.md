# Conformidad D-2: Región Única y Estrategia RPO 0

* **Región de despliegue:** Se establece **`us-east-1` (Norte de Virginia)** como la única región operativa para la base de datos (Amazon DynamoDB), optimizando los costos de transferencia y manteniendo una latencia aceptable hacia Bogotá.
* **Garantía de RPO 0 para pagos:** Dado que se opera en una sola región, la estrategia para lograr un *Recovery Point Objective* (RPO) estricto de cero en caso de una caída catastrófica de la base de datos en el momento exacto del cobro, se basa en la **conciliación asíncrona con la pasarela de pagos**. Si la base de datos falla antes de registrar un pago exitoso, la aplicación ejecutará un proceso de *reconciliation* (conciliación) consultando la API de Mercado Pago mediante el ID de la orden. Esto garantiza que el estado de "Pagado" se recupere desde la pasarela hacia la base de datos una vez restablecido el servicio, asegurando que ningún cliente pierda su dinero ni su boleta.
